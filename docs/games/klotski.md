# 华容道

房间内的单人游戏。房主在房间里选中本游戏并开始。登录、房间成员、对局状态、结束后的「退出游戏」走平台底座。棋盘和拖动在浏览器里用 PixiJS 绘制，服务端只校验步数。

- **gameId**: `klotski`
- **人数**: 1（`minPlayers = 1`，`maxPlayers = 1`）
- **棋盘**: 4 列 × 5 行，共 20 格。每道题曹操都占据第 1 行第 2～3 列、第 2 行第 2～3 列。其余是横将、竖将和四个兵，留下 2 个空格
- **历史**: 默认按最少步数。`rawScore` 是步数，越少越好

## 规则

一次按住并松手算一步。按住期间棋子可以沿空位连走多格，也可以拐弯，不能跳过别的棋子，也不能旋转。

曹操的左上角落到第 2 列、第 4 行（从 0 计为 `x = 1, y = 3`）时过关。他占据底边正中的 2×2，画面上这两格会淡淡标成金色，并写着「出口」。

撤销退回上一步，重来回到本布局的开局并重新计时。

## 布局

十道都是公开流传的经典开局，曹操都在顶上正中。少数布局会把竖将换成横将，棋子总数仍是 10 块。最短步数是「一次按住算一步、可以拐弯」的通行数字。对局页不显示最短步数。峰回路转的曹操不在顶上正中，所以没有收入。

| 布局 | `difficulty` | 通行最少步数 |
|---|---|---|
| 捷足先登 | `jiezu` | 32 |
| 兵分三路 | `bingfen` | 32 |
| 一路顺风 | `yilu` | 39 |
| 雨声淅沥 | `yusheng` | 47 |
| 左右布兵 | `zuoyou` | 54 |
| 齐头并进 | `qitou` | 60 |
| 指挥若定 | `zhihui` | 70 |
| 将拥曹营 | `jiangyong` | 72 |
| 横刀立马 | `hengdao` | 81 |
| 层层设防 | `cengceng` | 102 |

横刀立马：曹操在顶部正中，关羽横在他下方，两侧各两员竖将，两个兵在第四行中间，两个兵在底边两角，底边正中是空位。若把每段直线滑动单独计步，这盘是 90 步；本游戏按一次连续拖动计步，所以是 81 步。

## 成绩

完成后写入一条历史：

- `rawScore`：步数，范围 1～2000
- `durationMs`：毫秒
- `meta.kind = 'klotski'`，`meta.difficulty` 为布局 id，`meta.layoutName` 为布局名

服务端 `validateSubmit` 只检查步数和用时范围，不重演走法。介绍页用最少步数，历史条目显示「N 步」和布局名。

在房间里完成后仍调用平台 `complete()`，房间可以「退出游戏」。棋盘下方的「重开一局」回到选题，不离开当前房间。

## 代码落点

独立包 `games/klotski/`，在 `apps/web` 与 `apps/server` 注册插件。没有 `onStart`，也没有自己的 HTTP 或 WebSocket。

- `src/board.ts`：占格、一次拖动能到达的位置、过关判定
- `src/levels.ts`：十道布局
- `src/rules.ts`：成绩校验
- `src/web/Play.vue`：选布局、计步、撤销、提交
- `src/web/scene/KlotskiScene.ts`：用 PixiJS 画布局按钮、棋盘，以及带五官和冠帽的棋子

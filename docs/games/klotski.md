# 华容道

房间内的单人游戏。房主在房间里选中本游戏并开始。登录、房间成员、对局状态、结束后的「退出游戏」走平台底座。棋盘和拖动在浏览器里用 PixiJS 绘制，服务端只校验步数。

- **gameId**: `klotski`
- **人数**: 1（`minPlayers = 1`，`maxPlayers = 1`）
- **棋盘**: 4 列 × 5 行。曹操 2×2，关羽 2×1 横放，张飞、赵云、马超、黄忠各 1×2 竖放，四个兵各 1×1。剩下 2 个空格
- **历史**: 默认按最少步数。`rawScore` 是步数，越少越好

## 规则

一次按住并松手算一步。按住期间棋子可以沿空位连走多格，也可以拐弯，不能跳过别的棋子，也不能旋转。

曹操的左上角落到第 2 列、第 4 行（从 0 计为 `x = 1, y = 3`）时过关。他占据底边正中的 2×2，画面上这两格会淡淡标成金色，并写着「出口」。

撤销退回上一步，重来回到本布局的开局并重新计时。

## 布局

三盘都用上面这 10 块棋子。最短步数按「一次按住算一步、可以拐弯」搜索得到，形状相同的棋子视为可互换。对局页不显示最短步数。

| 布局 | `difficulty` | 最短步数 |
|---|---|---|
| 近在咫尺 | `easy` | 6 |
| 小试牛刀 | `normal` | 18 |
| 横刀立马 | `hard` | 81 |

横刀立马是常见开局：曹操在顶部正中，关羽横在他下方，两侧各两员竖将，两个兵在第四行中间，两个兵在底边两角，底边正中是空位。若把每段直线滑动单独计步，这盘是 90 步；本游戏按一次连续拖动计步，所以是 81 步。

## 成绩

完成后写入一条历史：

- `rawScore`：步数，范围 1～2000
- `durationMs`：毫秒
- `meta.kind = 'klotski'`，`meta.difficulty` 为 `easy` / `normal` / `hard`，`meta.layoutName` 为布局名

服务端 `validateSubmit` 只检查步数和用时范围，不重演走法。介绍页用最少步数，历史条目显示「N 步」和布局名。

在房间里完成后调用平台 `complete()`，进入结算。独立打开 `/game/klotski/play` 时，完成后可以「再来一局」。

## 代码落点

独立包 `games/klotski/`，在 `apps/web` 与 `apps/server` 注册插件。没有 `onStart`，也没有自己的 HTTP 或 WebSocket。

- `src/board.ts`：占格、一次拖动能到达的位置、过关判定
- `src/levels.ts`：三盘布局
- `src/rules.ts`：成绩校验
- `src/web/Play.vue`：选布局、计步、撤销、提交
- `src/web/scene/KlotskiScene.ts`：用 PixiJS 画布局按钮、棋盘、棋子和撤销

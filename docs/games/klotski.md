# 华容道

房间内的单人游戏。房主在房间里选中本游戏并开始。登录、房间成员、对局状态、结束后的「退出游戏」走平台底座。棋盘和拖动在浏览器里用 PixiJS 绘制，服务端只校验步数。

- **gameId**: `klotski`
- **人数**: 1（`minPlayers = 1`，`maxPlayers = 1`）
- **棋盘**: 4 列 × 5 行，共 20 格。每道题曹操都占据第 1 行第 2～3 列、第 2 行第 2～3 列。其余是横将、竖将和四个兵，留下 2 个空格
- **历史**: 默认按最少步数。`rawScore` 是步数，越少越好

## 规则

每颗棋子每移动一格算一步。单独一颗棋子可以沿空位连走多格，也可以拐弯：横着走的格数和竖着走的格数相加。同一列往上下拖、或同一排往左右拖时，如果被拖棋子的正前方紧挨着别的棋子，且最前面还有空位，就把前面的棋子一起推走，每颗棋子各自按走过的格数计步。旁边并排的棋子不跟着走。不能跳过别的棋子，也不能旋转。撤销退回上一次拖动，并减去这次拖动累加的步数。

曹操的左上角落到第 2 列、第 4 行（从 0 计为 `x = 1, y = 3`）时过关。他占据底边正中的 2×2，画面上这两格会淡淡标成金色，并写着「出口」。

重来回到本布局的开局并重新计时。

## 演示

对局中点「演示」，棋盘回到开局，按最少步数自动解题：每次一颗棋子走一格，然后停 1 秒，棋子平滑滑过去。顶部显示「演示 已走 / 最少 步」。演示中不能拖动，「停止演示」回到开局自己玩。演示完成后可以点「自己来」重新开局，或点「重开一局」回到选题。演示不提交成绩，也不结束房间对局。

解法由 `src/solver.ts` 在浏览器里现算：按每颗棋子每走一格算一步做广度优先搜索。推动和拐弯都能拆成单子单格移动，代价相同，所以搜到的就是本游戏计步下的最少步数。同形状的棋子互换算同一局面。十道题在电脑上各用时 30～300 毫秒。

## 布局

十道都是公开流传的经典开局，曹操都在顶上正中。少数布局会把竖将换成横将，棋子总数仍是 10 块。选题按钮、对局顶部和过关提示都显示「最少步数」，即本游戏按格计步的最优解，`levels.ts` 里写死为 `minSteps`，选题按它从少到多排列。「一次按住算一步」那列是经典记法，只作对照。峰回路转的曹操不在顶上正中，所以没有收入。

| 布局 | `difficulty` | 最少步数（按格） | 经典一次按住最少步数 |
|---|---|---|---|
| 捷足先登 | `jiezu` | 47 | 32 |
| 一路顺风 | `yilu` | 49 | 39 |
| 雨声淅沥 | `yusheng` | 60 | 47 |
| 左右布兵 | `zuoyou` | 78 | 54 |
| 齐头并进 | `qitou` | 85 | 60 |
| 兵分三路 | `bingfen` | 92 | 32 |
| 指挥若定 | `zhihui` | 100 | 70 |
| 将拥曹营 | `jiangyong` | 101 | 72 |
| 横刀立马 | `hengdao` | 116 | 81 |
| 层层设防 | `cengceng` | 138 | 102 |

横刀立马：曹操在顶部正中，关羽横在他下方，两侧各两员竖将，两个兵在第四行中间，两个兵在底边两角，底边正中是空位。经典记法里一次按住算一步，这盘是 81 步。本游戏里，一颗棋子横着走两格再竖着走一格记 3 步，两颗棋子一起走一格记 2 步。

## 成绩

完成后写入一条历史：

- `rawScore`：步数，范围 1～2000
- `durationMs`：毫秒
- `meta.kind = 'klotski'`，`meta.difficulty` 为布局 id，`meta.layoutName` 为布局名

服务端 `validateSubmit` 只检查步数和用时范围，不重演走法。介绍页用最少步数，历史条目显示「N 步」和布局名。

在房间里完成后仍调用平台 `complete()`，房间可以「退出游戏」。棋盘下方的「重开一局」回到选题，不离开当前房间。

## 代码落点

独立包 `games/klotski/`，在 `apps/web` 与 `apps/server` 注册插件。没有 `onStart`，也没有自己的 HTTP 或 WebSocket。

- `src/board.ts`：占格、单子拐弯、推着前方棋子一起走、过关判定
- `src/levels.ts`：十道布局和各自的最少步数
- `src/solver.ts`：按格计步的最短解搜索，供演示使用
- `src/rules.ts`：成绩校验
- `src/web/Play.vue`：选布局、计步、撤销、演示、提交
- `src/web/scene/KlotskiScene.ts`：用 PixiJS 画布局按钮、棋盘，以及带五官和冠帽的棋子

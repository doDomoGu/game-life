# 数独

房间内的单人游戏。房主在房间里选中本游戏并开始。登录、房间成员、对局状态、结束后的「退出游戏」走平台底座。出题、填写和计时在浏览器里完成，服务端只校验成绩。

- **gameId**: `sudoku`
- **人数**: 1（`minPlayers = 1`，`maxPlayers = 1`）
- **棋盘**: 9×9，每行、每列、每个 3×3 宫恰好出现 1～9 各一次
- **历史 `recordStyle`**: `time`。`rawScore` 为完成用时的整秒，越短越好

## 难度

开始后在对局页选择难度，再出题。给定数字的目标数量：

| 难度 | `difficulty` | 目标给定格 |
|---|---|---|
| 简单 | `easy` | 40 |
| 普通 | `normal` | 32 |
| 困难 | `hard` | 26 |

生成步骤在 `games/sudoku/src/sudoku.ts`：

1. 用随机回溯填满一盘合法终盘。
2. 按随机顺序挖空。每挖一格都确认剩余题目仍然只有一个解；会变成多解的格子填回去。
3. 挖到目标数量为止。若再挖就会破坏唯一解，给定格可能多于目标数量。

题目在浏览器里生成，不经过服务端。

## 填写

灰字是题目给定的数字，不能改，也不能擦除。空格用数字键盘填入 1～9，或擦除。

冲突只按「同一行、列或宫里出现了同一个数字」标红，不把玩家的填写和终盘对比，避免把答案露出来。格子填满且没有任何冲突即完成。唯一解保证这时的盘面就是那一个终盘。

## 成绩

完成后写入一条历史：

- `rawScore`：用时整秒，范围 1～86400
- `durationMs`：毫秒
- `meta.kind = 'sudoku'`，`meta.difficulty` 为 `easy` / `normal` / `hard`

服务端 `validateSubmit` 只检查秒数和 `durationMs` 是否在范围内，不检查盘面。介绍页和历史把最短 `rawScore` 显示成分秒，历史条目带难度。

在房间里完成后调用平台 `complete()`，进入结算。结算之后由玩家点击「退出游戏」，房间回到等待。独立打开 `/game/sudoku/play` 时，完成后可以「再来一局」，重新选难度。

## 代码落点

独立包 `games/sudoku/`，在 `apps/web` 与 `apps/server` 注册插件。没有 `onStart`，也没有自己的 HTTP 或 WebSocket。

- `src/sudoku.ts`：出题、唯一解检查、冲突、完成判定
- `src/rules.ts`：成绩校验
- `src/web/Play.vue`：难度、计时、提交
- `src/web/scene/SudokuScene.ts`：用 PixiJS 画难度按钮、棋盘和数字键盘

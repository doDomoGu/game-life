# 花火牌 HANABI

房间内的合作卡牌。房主在房间里选中本游戏并开始；人数不足或超出时不能开始。登录、房间成员、对局状态、结束后的「退出游戏」走平台底座。牌堆、手牌、提示和计分放在本游戏自己的会话里。

- **gameId**: `hanabi`
- **人数**: 最少 2，最多 5（`minPlayers = 2`，`maxPlayers = 5`）
- **手牌**: 2～3 人每人 **5** 张；4～5 人每人 **4** 张
- **历史 `recordStyle`**: `score`。`rawScore` 为五色烟花高度之和，满分 **25**

## 牌与开局

五种颜色：红、黄、绿、蓝、白。每种颜色的张数：1 有 3 张，2、3、4 各 2 张，5 有 1 张。一副共 50 张。

`onStart` 洗牌并按人数发牌。开局 **8** 枚提示令牌、**3** 次失误机会。五色烟花高度都是 0。行动顺序是开局时的玩家顺序，轮流进行。

自己的手牌正面不发给自己，只带已有的颜色提示和数字提示。队友的牌正面可见。

## 回合

轮到的玩家三选一：

- **提示**：消耗 1 枚提示令牌。指定一名队友，以及一种颜色或一个数字（1～5）。该玩家手中所有符合的牌都标上这个提示。不能提示自己。队友手里没有匹配的牌时，这次提示不成立。提示令牌为 0 时不能提示。
- **弃牌**：丢掉自己的一张牌，提示令牌 +1，最多回到 8。令牌已满时不能弃牌。然后从牌库补一张。
- **出牌**：打出自己的一张牌。它必须是该颜色当前高度 +1。打出该颜色的 5 时，若提示令牌未满，令牌 +1。接错则这张牌进入弃牌堆，失误 −1。然后从牌库补一张。

牌库抽空的那一次补牌之后进入终局：每位玩家（含抽到最后一张的人）再行动一轮，然后按当前五色高度结算。

## 结束

- 五色都打到 5：立即胜利，得分 25。
- 失误用完（第 3 次接错）：立即失败，得分是当时的五色高度之和。
- 终局轮次走完：按五色高度之和结算。

界面上的档位文案：0～5 Horrible，6～10 Mediocre，11～15 Honorable，16～20 Excellent，21～24 Amazing，25 Legendary。

每人写一条历史：`meta.kind = 'hanabi'`，带 `roomCode`、`result`（`win` / `lose` / `score`）、`scoreLabel`、`opponents`。然后调用平台 `finishRoom`。

## 断线

连接走平台 WebSocket 壳，路径 `/api/games/hanabi/rooms/:code/ws`。行动也可以走 `POST /api/games/hanabi/rooms/:code/action`。

当前行动玩家的连接断开时，其他人不能替他出牌、提示或弃牌。该玩家重连后可以继续自己的回合。断线不换人、不跳过。

## 代码落点

独立包 `games/hanabi/`，在 `apps/web` 与 `apps/server` 注册插件。

- `src/server/engine.ts`：牌堆、提示、出牌、弃牌、终局和分数。改规则时改这里。
- `src/server/rooms.ts`：内存会话、按视角过滤手牌、写历史
- `src/server/routes.ts`：HTTP 与 WebSocket
- `src/web/Game.vue`：对局界面

会话存在服务端进程内存里。进程重启后进行中的对局消失。
